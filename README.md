- **400+ agent benchmark tasks** in Harbor format: Terminal-Bench, multi-agent (SwarmBench) and enterprise-tool tasks over MCP
- **Pod lead, LLM evaluation** at Turing (Terminal Bench, OS Bench, SWE-Bench)
